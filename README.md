FA 5 – Linear Models

Project Overview
This project analyzes penguin body mass according to species and sex using the Palmer Penguins dataset.

Methods
- Descriptive statistics
- One-way ANOVA
- Dummy variable regression
- Two-way ANOVA
- Interaction analysis

Key Findings
- Penguin body mass differs significantly across species.
- Gentoo penguins have the highest average body mass.
- Male penguins are generally heavier than female penguins.
- The difference in body mass between males and females varies by species.

Dataset Source
Palmer Penguins dataset: https://github.com/allisonhorst/palmerpenguins

Conclusion
The results show that both species and sex are associated with penguin body mass. Their combined relationship also affects the differences observed in body mass.
